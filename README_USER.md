# HiJapan 用户使用说明

本文档面向下载和使用 HiJapan 的普通用户，对应 `0.1.1 开发预览版`。后续版本新增或调整功能时，应同步更新本文档。

## 1. 软件能做什么

HiJapan 是一款在 Windows 电脑本地运行的日语学习软件。当前重点是赴日旅行前的实用学习：

- 按酒店、餐厅、购物和景点四类场景学习高频词汇与固定表达。
- 听系统日语语音，学习假名、中文含义和用法提示。
- 阅读成组的固定场景对话。
- 按每日可用时间生成今日任务。
- 将学过的内容加入间隔复习，并根据“忘记、困难、记得、轻松”调整下次复习时间。
- 用户自行配置 AI API 后，与 AI 扮演的店员、前台等角色进行文字练习，并获得复盘建议。

课程学习不依赖 AI。即使完全不配置 API，也可以使用旅行课程、固定对话、今日计划和复习功能。

## 2. 系统要求

- Windows 10 或 Windows 11，64 位。
- 建议至少保留 500 MB 可用磁盘空间。
- 普通课程可离线使用；AI 对话需要联网。
- 普通用户不需要安装 Node.js、Python、SQLite 或任何服务器。

## 3. 下载与安装

### 推荐：安装版

1. 从项目官方 GitHub Releases 下载 `HiJapan 日语随行-x.y.z Setup.exe`。
2. 双击安装包并按提示安装。
3. 安装完成后，从开始菜单或桌面快捷方式启动 HiJapan。

当前预览版尚未购买代码签名证书，Windows 可能显示未知发布者。如果文件来自项目官方 Releases，可在核对版本和 SHA-256 后选择继续；不要运行来历不明的副本。

### 免安装便携版

1. 下载 `HiJapan 日语随行-win32-x64-x.y.z.zip`。
2. 将压缩包完整解压到一个可写目录。
3. 运行解压目录中的 `HiJapan 日语随行.exe`。

不要直接在压缩包预览窗口里运行，也不要只复制一个 `.exe`；程序需要同目录内的其他文件。

### 校验下载文件

在安装包所在文件夹打开 PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\HiJapan 日语随行-0.1.1 Setup.exe'
```

把结果与同一 Release 中的 `SHA256SUMS.txt` 对照。

## 4. 第一次启动

软件会先显示 HiJapan 启动画面，然后进入两步配置。

### 第一步：AI API（可以跳过）

如果暂时只想学习课程，点击“暂不配置，先使用本地课程”。之后随时可以在“设置”中配置。

需要 AI 对话时填写：

- **API 地址**：服务商提供的 OpenAI-compatible Base URL。通常应使用 `https://`。
- **模型名称**：服务商账户能够调用的模型 ID，必须与服务商文档一致。
- **API Key**：由服务商创建的个人密钥。

点击保存/测试后，软件会直接从这台电脑连接该服务商。本项目没有中转服务器，也不提供公共 Key。请关注服务商的计费、隐私和数据保留规则，不要使用来源不明的共享 Key。

### 第二步：学习目标

1. 填写称呼（可选）。
2. 选择当前日语水平。
3. 选择每天计划学习的时间。
4. 至少选择一个重点旅行场景。
5. 点击“开始学习”。

## 5. 主界面功能

### 今日

“今日”页面根据每日时间、到期复习和未完成课程生成任务。一般先处理到期复习，再学习新课程。点击任务即可进入对应页面。

### 学习

1. 在顶部选择酒店、餐厅、购物或景点场景。
2. 在“课程”标签中选择一节课。
3. 使用“播放”听系统日语朗读。
4. 对每张卡片选择“需要复习”或“记住了”。
5. 完成整节课后，难点会更早出现在复习队列中。

切换到“固定对话”标签，可以查看同一场景下的完整双方对话，并逐句朗读。

### 对话

自由对话需要先在“设置”中配置并成功测试 AI API。

1. 选择场景、难度和纠错方式。
2. 开始对话后，用日语或中日混合文字回复场景角色。
3. 点击结束并复盘，查看做得好的地方、可改写表达和建议复习内容。

AI 输出可能出错，不应把它当作签证、法律、医疗或紧急事务的唯一依据。使用对话功能可能产生用户所选服务商的 API 费用。

### 复习

到期卡片会按计划出现。查看答案后选择：

- **忘记**：很快再次出现。
- **困难**：缩短下次间隔。
- **记得**：按正常间隔推进。
- **轻松**：延长下次间隔。

### 设置

- 修改或删除 AI API 配置。
- 导出本地学习备份。
- 导入之前的备份。
- 删除全部学习数据。

删除 AI 配置后，普通课程仍然可用。导出的备份不会包含 API Key；在另一台电脑恢复后，需要重新填写 Key。

## 6. 本地数据与备份

学习数据库和加密后的凭据保存在 Windows 当前账户的应用数据目录中。一般不需要手动编辑这些文件。

建议在“设置”中定期导出 `.hijapan-backup.json` 文件，并将备份放在可靠位置。导入备份会替换当前学习记录；导入前先导出一份现状备份。

执行“删除全部数据”会清空学习进度、复习记录、对话记录和 AI 配置。该操作不可通过软件撤销。

## 7. 常见问题

### 不配置 AI 能否使用？

可以。旅行课程、固定对话、朗读、今日计划和复习全部是本地功能。

### 为什么 AI 连接测试失败？

依次检查 Base URL、模型 ID、API Key、账户余额和网络代理。模型名称不能凭空填写，应以服务商控制台为准。

### 为什么没有 JLPT 完整课程？

当前版本先完成旅行模式。JLPT 题库需要按 N5—N1 分级整理和人工审核，项目不会用 AI 临时生成内容冒充正式考题。

### 语音为什么听起来与真人不同？

当前使用 Windows 系统语音。不同电脑安装的日语语音包不同，声音质量也会不同。可在 Windows 语言和语音设置中安装日语语音。

### 如何报告问题？

在 GitHub Issues 中提供软件版本、Windows 版本、复现步骤和错误提示。请先删除截图或日志中的 API Key、个人对话和其他敏感信息。
