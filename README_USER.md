# HiJapan 用户使用说明

本文档面向下载和使用 HiJapan 的普通用户，对应 `0.1.7 开发预览版`。本版新增桌面学习伙伴，保留五十音、JLPT N5—N1、旅行课程与 AI 对话。

## 1. 软件能做什么

HiJapan 是一款在 Windows 电脑本地运行的日语学习软件。当前重点是赴日旅行前的实用学习：

- 分 5 节学习五十音，每节两行，从「あ行・か行」逐步学到「ら行・わ行」。
- 用已经学过的假名拼读带汉字写法、平假名注音和中文释义的词语。
- 自由选择完整学习、三列连线或歌牌翻牌复习，也可以跳过已经掌握的内容。
- 按酒店、餐厅、购物和景点四类场景学习高频词汇与固定表达。
- 听系统日语语音，学习假名、中文含义和用法提示。
- 阅读成组的固定场景对话。
- 按每日可用时间生成今日任务。
- 将学过的内容加入间隔复习，并根据“忘记、困难、记得、轻松”调整下次复习时间。
- 用户自行配置 AI API 后，与 AI 扮演的店员、前台等角色进行文字练习，并获得双语回复和复盘建议。
- 在本机查看、继续或删除最近 7 天的 AI 对话记录。
- 使用透明桌宠陪伴学习、查看课程完成鼓励，并通过互动菜单返回学习或对话。

课程学习不依赖 AI。即使完全不配置 API，也可以使用旅行课程、固定对话、今日计划和复习功能。

## 2. 系统要求

- Windows 10 或 Windows 11，64 位。
- 建议至少保留 500 MB 可用磁盘空间。
- 普通课程可离线使用；AI 对话需要联网。
- 普通用户不需要安装 Node.js、Python、SQLite 或任何服务器。

## 3. 下载与安装

当前推荐下载 `HiJapan 日语随行-win32-x64-0.1.7.zip`。不要把 GitHub 自动生成的 `Source code (zip)` 当作应用安装包。

### 安装版（0.1.7 暂未提供）

当前交付完整便携 ZIP；后续 Release 提供 `HiJapan 日语随行-x.y.z Setup.exe` 时，才按安装包提示操作。

当前预览版尚未购买代码签名证书，Windows 可能显示未知发布者。如果文件来自项目官方 Releases，可在核对版本和 SHA-256 后选择继续；不要运行来历不明的副本。

### 推荐：0.1.7 免安装便携版

1. 下载 `HiJapan 日语随行-win32-x64-x.y.z.zip`。
2. 将压缩包完整解压到一个可写目录。
3. 运行解压目录中的 `HiJapan 日语随行.exe`。

不要直接在压缩包预览窗口里运行，也不要只复制一个 `.exe`；程序需要同目录内的其他文件。

本地预览交付会同时准备解压目录 `dist/x.y.z-preview/HiJapan-x.y.z-portable/`，可直接双击其中的 `HiJapan 日语随行.exe`。GitHub Release 通常只提供 ZIP，下载后仍需先执行“全部解压”才能看到并正常使用该 EXE。

### 校验下载文件

在安装包所在文件夹打开 PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\HiJapan 日语随行-win32-x64-0.1.7.zip'
```

结果应与同一 Release 中 `SHA256SUMS.txt` 对应 ZIP 条目的哈希一致。

## 4. 第一次启动

软件会先显示 HiJapan 启动画面，然后进入两步配置。

### 第一步：AI API（可以跳过）

如果暂时只想学习课程，点击“暂不配置，先使用本地课程”。之后随时可以在“设置”中配置。

需要 AI 对话时填写：

- **API 地址**：服务商提供的 OpenAI-compatible Base URL。通常应使用 `https://`。
- **模型名称**：服务商账户能够调用的模型 ID，必须与服务商文档一致。
- **API Key**：由服务商创建的个人密钥。

点击保存/测试后，软件会直接从这台电脑连接该服务商。本项目没有中转服务器，也不提供公共 Key。请关注服务商的计费、隐私和数据保留规则，不要使用来源不明的共享 Key。

### 第二步：学习目标

1. 填写称呼（可选）。
2. 选择当前日语水平。
3. 选择每天计划学习的时间。
4. 至少选择一个重点旅行场景。
5. 点击“开始学习”。

## 5. 主界面功能

### 今日

“今日”页面根据每日时间、到期复习和未完成课程生成任务。一般先处理到期复习，再学习新课程。点击任务即可进入对应页面。

### 学习

“学习”页面提供“五十音基础”“JLPT N5—N1”和“旅行场景日语”三个本地资料入口。

五十音基础：

1. 五节课程均可自由打开；推荐从「あ行・か行」开始，但熟悉部分五十音的用户不必逐节解锁。
2. 进入一节课时先选择“完整学习”“本节连线复习”“累计连线复习”或“直接翻牌复习”。第一节没有此前内容，因此不会显示累计连线选项。
3. 选择完整学习后，可以逐个认识平假名、片假名和罗马音；圆形喇叭按钮用于朗读。也可以选择“跳过认识”直接进入词语拼读。
4. 拼读词语只由当前及此前已学假名组成，同时显示日语写法、平假名注音和中文含义；不需要时可以跳过。
5. 连线复习从三列中依次选出属于同一个假名的平假名、片假名和罗马音。正确后选项变绿、显示词例并自动朗读一次。
6. 翻牌复习中先后翻开两张歌牌；属于同一个假名的不同形式会消去，不匹配则自动翻回鸟居或樱花牌背。
7. 如果已经掌握某节内容，可以点击“标记掌握并跳过本节”。课程以后仍可重新打开学习或复习。

旅行场景日语：

1. 选择酒店、餐厅、购物或景点场景。
2. 在“课程”标签中选择一节课。
3. 使用“播放”听系统日语朗读。
4. 对每张卡片选择“需要复习”或“记住了”。
5. 完成整节课后，难点会更早出现在复习队列中。

切换到“固定对话”标签，可以查看同一场景下的完整双方对话，并逐句朗读。

### 对话

自由对话需要先在“设置”中配置并成功测试 AI API。

1. 选择场景、难度和纠错方式。
2. 开始对话后，用日语或中日混合文字回复场景角色。
3. AI 按“日语正文（中文翻译）”格式回复；点击回复旁的扬声器只朗读日语正文。
4. 点击结束并复盘，查看做得好的地方、可改写表达和建议复习内容。
5. 点击“近 7 天记录”回看历史；未结束的对话可以继续，已结束的对话只读。记录可单条删除或全部清空，超过 7 天会自动从本机删除。

AI 输出可能出错，不应把它当作签证、法律、医疗或紧急事务的唯一依据。使用对话功能可能产生用户所选服务商的 API 费用。

### 复习

到期卡片会按计划出现。查看答案后选择：

- **忘记**：很快再次出现。
- **困难**：缩短下次间隔。
- **记得**：按正常间隔推进。
- **轻松**：延长下次间隔。

### 设置

- 修改或删除 AI API 配置。
- 导出本地学习备份。
- 导入之前的备份。
- 删除全部学习数据。

删除 AI 配置后，普通课程仍然可用。导出的备份不会包含 API Key；在另一台电脑恢复后，需要重新填写 Key。

## 6. 本地数据与备份

学习数据库和加密后的凭据保存在 Windows 当前账户的应用数据目录中。一般不需要手动编辑这些文件。AI 对话保存在本地 SQLite 中，仅保留最近 7 天；朗读由 Windows 系统语音即时生成，不会下载或保存 AI 音频。

正常升级不会要求重新配置：相同 Windows 账户下的 HiJapan 安装版和便携版默认共用同一个应用数据目录，因此课程进度、对话历史和 AI 配置会延续到新版本。旧版本安装包只是安装文件；运行它们或从旧便携目录启动程序时，也可能读取同一份本地数据。需要从空白状态测试时，请先导出备份，再在设置中删除全部本地数据。

建议在“设置”中定期导出 `.hijapan-backup.json` 文件，并将备份放在可靠位置。导入备份会替换当前学习记录；导入前先导出一份现状备份。

执行“删除全部数据”会清空学习进度、复习记录、对话记录和 AI 配置。该操作不可通过软件撤销。

## 7. 常见问题

### 不配置 AI 能否使用？

可以。五十音、旅行课程、固定对话、朗读、今日计划和复习全部是本地功能。

### 为什么 AI 连接测试失败？

依次检查 Base URL、模型 ID、API Key、账户余额和网络代理。模型名称不能凭空填写，应以服务商控制台为准。

### 为什么软件版本和教材包版本不同？

软件和教材包分别管理版本。首页“软件版本”表示当前运行的 HiJapan 程序版本，例如 `0.1.3`；设置页“教材包版本”表示随软件导入的课程内容版本，当前可能仍为 `0.1.0`。教材包没有变化时不会为了跟随软件版本而重复编号。

### 如何使用桌面学习伙伴？

默认在屏幕右下角显示，拖动角色移动位置；单击、右键或点击底部状态条打开菜单，双击进入学习。菜单可打招呼、鼓励、休息、睡眠、进入学习/对话，或隐藏桌宠；休息与睡眠期间点击菜单中的“唤醒”恢复陪伴。

“设置 → 桌面学习伙伴”可显示/隐藏桌宠、锁定位置、减少动画、关闭提示气泡、选择 75%/100%/125% 大小，或重置到屏幕右下角。偏好与位置保存在应用数据目录的 `desktop-pet.json`，下次启动继续生效；学习备份不包含这些桌面偏好，“删除全部数据”会一并清除并隐藏桌宠。

课程完成和复习提交后出现短暂鼓励；学习页面显示陪伴状态，朗读期间显示发音提示，主动 AI 请求等待期间显示思考提示。陪伴、设置和动作不会调用 AI。主窗口最小化后仍可互动，关闭软件时桌宠退出。

当前已有十二种独立透明关键姿势，随待机、挥手、学习、思考、讲解、鼓励、休息、睡眠、拖拽及手动行走/聆听/提示动作切换，配合轻量动效；尚无连续逐帧表情、自由走动、语音识别或定时休息提醒。聆听动作不启动麦克风。

### 如何直接与桌宠聊天、设置人设？

桌宠默认正常聊天。日语招呼、日常心情或普通闲聊不会自动变成翻译讲解，不检索或推荐课程，也不附加巩固题；只有明确求教、要求翻译/读音/语法或练习时，才启用学习辅助。人设会影响语气，但不会让导师角色在闲聊时强行上课。

先在主窗口“设置 → AI API”配置并测试连接，桌宠共用这套服务商、模型和加密 Key。点击桌宠菜单中的“与桌宠聊天”，输入问题并发送。消息、最近十二条对话上下文、人设和最多六条相关课程摘要会提交给所选服务商；普通待机不调用 API。请求超时约 35 秒后可重试。

在“设置 → 桌面学习伙伴”选择开朗搭档、温柔导师或聪明慵懒的傲娇鲸鱼少女，并独立选择朋友、师生或成年虚构恋人关系。自定义人设框支持粘贴 PERSONA_LOAD 风格文本，离开输入框保存；不要填写 API Key。鲸鱼角色的尾鳍、口粮等属于语言设定，不改变当前星饰角色外观。

回答学习问题时，会根据本地检索到的课程显示可点击推荐；模型漏掉课程时，程序补充检索候选，拒绝虚构 ID。可打开对应五十音、旅行或 JLPT 课程，JLPT 卡片另提供随机选择的翻牌、读音连线或句子补全专项入口。AI 也可反问一道巩固题，直接在桌宠输入答案继续交流。没有匹配课程时不强行伪造推荐。

桌宠对话单独保存至 userData 下的 pet-chat.json，保留近七天、最多四十条消息，可在聊天面板清除；清除全部本地数据也会删除。学习数据库备份不包含桌宠聊天或桌面偏好。模型解释仍可能出错，课程内容继续保留待审状态。

### 如何使用 JLPT N5—N1 课程？

1. 在“学习”页选择“JLPT N5—N1”，再选择 N5、N4、N3、N2 或 N1。
2. 每节预计 5—10 分钟，一般包含约 10 个新词和 0—2 个语法点。
3. 单词卡同时显示日语表记、读音和中文释义；可点击喇叭使用 Windows 日语语音朗读。
4. 语法卡给出接续、功能、完整例句和整句中文释义。例句中每个词块下有虚线，点击词块即可查看释义或语法作用。页面默认显示一个主例句；如有其他例句，点击“更多示例”后可在下方展开，避免一次显示过多文字。
5. 学完后先做读音匹配：左列只显示平假名读音，右列显示“日语单词（中文释义）”，避免只凭汉字直接猜中中文意思。配对正确后会自动朗读一次。
6. 句子测试包含两种题型：句子补全会空出一至两个词块，并混入干扰项；完整组句要求按中文排列全部词块。句末和句中标点由题目固定显示，不需要选择；动词词干、活用和助动词会合并成“食べます”这类完整词块。
7. 词汇翻牌是可选游戏；需要将平假名读音牌与对应的“日语单词（中文释义）”牌配对，不再使用容易凭汉字猜出的“单词 ↔ 单独中文义”组合。
8. 完成至少一节后可使用“综合复习”。题目只从当前等级中已记录为完成的课程抽取，不会考未学内容。

JLPT 课程完全在本地运行，不需要 API。当前资料仍是开发审阅版，等级划分来自社区资料而非 JLPT 官方固定词表，中文机翻与日语例句尚待人工审核；阅读、听力和完整模拟题也尚未开放。

### 语音为什么听起来与真人不同？

当前使用 Windows 系统语音，不是 AI 服务商返回的音频。软件会优先选择 `ja-JP` 日语声音，并在双语回复中去除括号内中文后再朗读。不同电脑安装的日语语音包不同，声音质量也会不同；可在 Windows 语言和语音设置中安装日语语音。

### 启动时为什么曾出现绿色矩形？

这不是正常加载组件，也不是所有软件都会出现。它通常是 Electron/Chromium 在特定 Windows 显卡驱动或运行环境下首次合成窗口时产生的短暂 GPU 纹理异常。0.1.4 在 Windows 上改用软件渲染，并让 HiJapan 启动画面以全窗口最高层至少显示约 2.6 秒，直到本地数据准备完成。软件以课程和文字界面为主，关闭硬件加速不会影响主要学习功能，但会略微增加少量 CPU 绘制开销。

### 双击 0.1.5 后为什么没有反应？

最初生成的 0.1.5 便携包缺少 Windows EXE 内的 ASAR 完整性记录，进程会在窗口出现前退出。该问题已经在同版本 0.1.5 中重新打包修复。请删除旧的 0.1.5 解压目录，重新下载并完整解压修正版；当前 ZIP 的 SHA-256 应为 `054C6FCDB02EF9A779793A7B8AF638BB38A4A23ED52C9D808AC3409CC732FFC4`。不要只用新版 EXE 覆盖旧目录，因为 EXE 与 `resources/app.asar` 必须来自同一次构建并且摘要匹配。

### 如何报告问题？

在 GitHub Issues 中提供软件版本、Windows 版本、复现步骤和错误提示。请先删除截图或日志中的 API Key、个人对话和其他敏感信息。
