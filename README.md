## 项目简介

HiJapan 是一款面向中文用户的日语学习桌面软件。它希望让不同目标的学习者走不同的学习路径：准备去日本旅行时，优先掌握点餐、住宿、购物和预约等真正会用到的内容；准备 JLPT 时，则按等级和考试目标组织词汇、语法、阅读、听力与复习；想练习表达时，可以使用自己选择的 AI 服务进行场景对话。

项目目前优先支持 **Windows 10/11 64 位**，采用 Electron + React + TypeScript 开发。课程、进度、复习记录和最近 7 天的对话历史都保存在用户自己的电脑中，不需要注册账号，也不需要部署服务器。

项目坚持以下原则：

- **本地学习优先**：五十音、旅行课程、今日计划、固定对话和复习不调用 AI。
- **AI 完全可选**：不配置 API 也能正常学习；只有用户主动使用自由对话时才会联网。后续会进一步完善AI功能，不限于AI评估课程进度选择合适的学习强度和难度以及AI桌宠等功能。
- **用户自带 API Key（BYOK）**：软件不内置公共 Key，也不经过 HiJapan 中转服务器。
- **内容与 AI 分离**：课程内容来自本地课程库，不让 AI 临时生成内容冒充正式教材或 JLPT 真题。
- **数据由用户掌控**：支持本地备份、恢复、删除对话和清除全部数据。

## 当前可以做什么

- 分 5 节学习五十音，每节两行，覆盖 46 个清音假名。
- 自由选择完整学习、本节连线、累计连线或歌牌翻牌复习，也可以跳过已经掌握的内容。
- 使用平假名、片假名和罗马音进行三列匹配；正确后查看词例并自动听取读音。
- 学习酒店住宿、餐厅点餐、购物付款和景点预约四个重点旅行场景，共 20 课。
- 使用 438 个词汇、231 条语句、30 个微语法和 72 行固定场景对话。
- 根据每日时间查看今日任务，并用“忘记、困难、记得、轻松”进行间隔复习。
- 使用 Windows 日语系统语音朗读假名、词汇、句子和 AI 回复中的日语正文。
- 配置 OpenAI-compatible API，进行双语文字角色对话并获得结构化复盘。
- 在本机查看、继续或删除最近 7 天的 AI 对话记录。
- 导出和导入本地学习备份，或者删除全部本地数据与 AI 配置。

完整 JLPT N5—N1 课程、语音识别和实时语音对话仍在规划中，当前版本不会用 AI 临时生成题库来代替正式教学内容。

## 下载与安装

### 1. 下载正确的文件

进入仓库右侧的 **Releases** 页面，打开最新版本。普通用户不要下载 GitHub 自动生成的 `Source code (zip)` 或 `Source code (tar.gz)`，它们是源代码，不是可直接运行的软件。

当前推荐下载：

| Release 文件                           | 适用情况               | 使用方法                                        |
| -------------------------------------- | ---------------------- | ----------------------------------------------- |
| `HiJapan 日语随行-win32-x64-x.y.z.zip` | 免安装便携版，当前推荐 | 完整解压后运行文件夹中的 `HiJapan 日语随行.exe` |
| `HiJapan 日语随行-x.y.z Setup.exe`     | 某个版本提供安装包时   | 双击安装，随后从开始菜单启动                    |
| `SHA256SUMS.txt`                       | 校验下载是否完整       | 使用 PowerShell 计算 SHA-256 后对照             |

### 2. 使用便携版

1. 右键下载的 ZIP，选择“全部解压”。
2. 将整个文件夹解压到桌面、文档或其他可写目录。
3. 打开解压后的文件夹，双击 `HiJapan 日语随行.exe`。
4. 不要只把 EXE 单独移动出去；同目录下的 `resources`、DLL 和其他文件都是程序运行所必需的。

普通用户不需要安装 Node.js、SQLite、开发工具或服务器。当前程序尚未购买商业代码签名，Windows SmartScreen 可能显示“未知发布者”；请确认文件来自本项目官方 Releases，并按需核对 SHA-256。

在下载目录打开 PowerShell，可以这样校验：

```powershell
Get-FileHash '.\HiJapan 日语随行-win32-x64-x.y.z.zip' -Algorithm SHA256
```

计算结果应与同一 Release 中的 `SHA256SUMS.txt` 一致。

## 第一次启动与 API 配置

软件启动后会先显示 HiJapan 启动画面，然后进入首次配置。

### 不需要 AI

点击 **“暂不配置，先使用本地课程”**，再设置称呼、当前水平和每日学习时间即可。之后仍可在“设置”页面补充 API 配置。

### 需要 AI 对话

请先从你信任的 AI 服务商处创建个人 API Key，然后填写：

- **API Base URL**：服务商提供的 OpenAI-compatible 基础地址，通常以 `https://` 开头，例如 `https://example.com/v1`。
- **模型名称**：你的账户实际能够调用的模型 ID，必须与服务商控制台或文档完全一致。
- **API Key**：服务商为你创建的个人密钥。

填写时请注意：

1. 地址框只填写原始 URL，不要粘贴 Markdown 链接、引号或 `LLM_BASE_URL=` 等环境变量格式。
2. 当前版本要求服务商兼容 `POST /chat/completions`，软件会在 Base URL 后自动补充 `/chat/completions`；如果服务商只支持其他协议，可能无法连接。
3. 点击 **“测试连接并保存”**。测试会发送一条很短的请求，可能产生极少量 API 费用。
4. 如果失败，请依次检查 Base URL、模型 ID、API Key、账户余额、服务商权限和本机网络代理。
5. 不要使用来历不明的共享 Key，也不要把 Key 发到 Issue、截图、日志或公开聊天中。如果 Key 曾经公开，请立即在服务商控制台撤销并重新创建。

HiJapan 没有 AI 中转服务器。对话请求会从你的电脑直接发送到你填写的服务商，相关费用、隐私和数据保留规则由该服务商决定。

## 如何使用 HiJapan

### 今日

“今日”页会根据每日时间、到期复习和未完成课程安排任务。通常先完成到期复习，再进入新课程。

### 学习

“学习”页目前包含两个本地入口：

- **五十音基础**：五节均可自由打开。可以完整学习，也可以直接做本节连线、累计连线或翻牌复习；第一节因为没有此前内容，不显示累计连线。
- **旅行场景日语**：按酒店、餐厅、购物、景点浏览课程，依次学习词汇、句子、微语法和固定对话。

喇叭按钮使用 Windows 系统语音朗读日语。声音效果取决于电脑是否安装了 `ja-JP` 日语语音包。

### 对话

“对话”需要已经成功测试的 AI API 配置：

1. 选择场景、难度和纠错方式。
2. 使用文字与 AI 进行角色对话。
3. AI 会尽量用“日语（中文翻译）”的形式回复。
4. 结束后查看任务完成度、优点、修改建议和可复习表达。
5. 点击“近 7 天记录”可以回看历史；未结束会话可以继续，已结束会话以只读方式保存。

AI 可能产生错误或不自然表达，请不要把它作为签证、法律、医疗、财务或紧急事务的唯一依据。

### 复习与设置

- 在“复习”中查看到期卡片，先回忆答案，再选择记忆程度。
- 在“设置”中修改或删除 AI 配置、导出备份、导入备份或删除全部本地数据。
- 相同 Windows 账户下的多个 HiJapan 版本默认共用同一个应用数据目录，因此升级后一般会保留进度和配置。
- 备份文件不包含 API Key；在另一台电脑恢复备份后，需要重新配置密钥。

更完整的操作与故障排除请阅读：[用户使用说明](README_USER.md)。

## AI 使用说明

| 功能                             | 是否使用 AI | 是否联网 |
| -------------------------------- | :---------: | :------: |
| 五十音学习、连线和翻牌           |     否      |    否    |
| 旅行单词、语句、微语法和固定对话 |     否      |    否    |
| 今日计划和间隔复习               |     否      |    否    |
| Windows 系统语音朗读             |     否      |    否    |
| 自由文字对话                     |     是      |    是    |
| 对话结束后的 AI 复盘             |     是      |    是    |
| JLPT 阶段测试 AI 分析            |  尚未开放   |    —     |

安全与隐私边界：

- API Key 由 Electron 主进程调用 Windows `safeStorage` 加密保存，不写入课程数据库、普通日志或学习备份。
- 页面只能看到 Key 的遮罩信息，不能从渲染层取回完整密钥。
- 对话历史保存在本地 SQLite，仅保留最近 7 天，可以提前删除。
- 系统朗读使用 Windows `speechSynthesis`，不会向 AI 服务商申请或保存音频。
- 使用 AI 时，服务商仍会收到完成请求所必需的对话内容；请自行阅读服务商的隐私政策。
- 删除 API 配置后，五十音、旅行课程、今日计划和复习仍然可以正常使用。

## 本地数据与隐私

HiJapan 不提供登录、云同步、远程数据库或行为广告。学习进度、复习队列、课程记录、普通设置和对话历史保存在当前 Windows 用户的应用数据目录中。

纯本地版本不会自动跨设备同步。需要换电脑时，请先在“设置”中导出 `.hijapan-backup.json`，再在新电脑中导入。导入会替换当前学习记录，因此建议先备份现状。
