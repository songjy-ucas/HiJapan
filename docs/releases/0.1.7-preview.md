# HiJapan 0.1.7 桌宠开发预览版

日期：2026-11-10。

## 默认自然聊天修复

日语招呼和普通闲聊只正常回应，不自动翻译、教学、出题或推荐课程。只有明确的学习/翻译/语法/读音请求才发送课程摘要并启用推荐；程序会移除普通聊天响应中误返回的课程卡和巩固题。搭档及导师的预设不再强制举例讲解。版本继续保持 0.1.7，新的 ZIP 哈希以 SHA256SUMS 为准。

## 同版本桌宠增强

新增桌宠直接聊天、三种性格与三种人物关系、自定义人设、真实课程检索与强制 ID 校验推荐、课程/专项练习直达和反问巩固。共用用户 API，只有发送消息时联网；聊天在本地保存七天/四十条，可清除。

十二种独立关键姿势已接入两张透明图集，仍未制作连续逐帧动画。普通待机不消耗 API。使用本机模拟服务完成端到端聊天及推荐、三类专项入口验收，课程相关测试总计 36 项通过；真实服务商仍取决于用户的 API 配置。

## 新增内容

- 独立透明、置顶的桌面学习伙伴，使用蓝紫星饰 Q 版透明立绘。
- 支持拖动、单击/右键互动菜单、双击学习、隐藏后从设置恢复；最小化主窗口继续显示，关闭软件一起退出。
- 提供打招呼、鼓励、休息、睡眠和唤醒；学习、完课、复习、朗读与用户发起 AI 请求时显示相应状态。
- 设置中支持位置锁定、气泡开关、减少动画、三档大小和位置重置；本地保存偏好和位置。
- 桌宠独立 preload 仅暴露自身操作，无法访问主应用 API、数据库、备份与用户 API Key。

## 交付范围

本版使用透明立绘与 CSS 呼吸、摆动、轻跳、状态饰物，未将十二姿势图作为逐帧动画播放；独立挥手、自由行走、表情骨骼、语音识别和休息计时尚未实现。日常陪伴不调用 AI；“去对话”只打开主窗口，用户发送才请求自己的服务商。

App 版本为 0.1.7，JLPT 内容版本保持 0.1.6，旅行教材版本保持 0.1.0。课程仍是待母语审核草稿。

## 数据

偏好存储于 userData/desktop-pet.json，只有显示、锁定、减少动画、气泡、大小和位置；学习备份不包含此文件。全部数据删除会清除桌宠偏好并隐藏桌宠。沿用现有用户数据目录，升级后无需重复建档。

## Windows 交付

- 便携目录：`dist/0.1.7-preview/HiJapan-0.1.7-portable/`。
- ZIP：`HiJapan 日语随行-win32-x64-0.1.7.zip`，完整解压后运行目录内同名 EXE；不要单独复制 EXE。
- SHA-256 以同目录 `SHA256SUMS.txt` 为准。
- 当前提供便携 ZIP，未生成 Setup。Forge 完成生产编译后在运行时复制下载阶段出现 `fetch failed`，使用已缓存官方 Electron 45.1.0 完整运行时与相同生产代码完成便携打包。
