# HiJapan 0.1.2 开发预览版

## 本次改进

- AI 自由对话记录保存在本地 SQLite，并提供近 7 天历史入口。
- 未结束的历史对话可以继续；已结束的对话以只读方式回看。
- 支持删除单条记录或清空全部记录，超过 7 天的记录自动删除。
- 自由对话 Prompt 统一要求“日语正文（中文翻译）”双语格式。
- 系统朗读会先移除括号内中文，只把日语正文交给 Windows `ja-JP` TTS。
- 增加对话保留、数据库清理和朗读文本提取测试。

## 数据与联网说明

- 对话记录只保存在用户电脑，不经过 HiJapan 自建服务器。
- 发送消息和生成复盘时，内容仍会直接提交给用户配置的 AI 服务商。
- 朗读使用 Windows 系统语音，不请求或保存 AI 音频。
- API Key 仍由 Windows 系统能力加密保存，不进入 SQLite 或备份。

## 仍然存在的限制

- 教材状态仍为 `draft_needs_native_review`，未完成日语母语者终审。
- AI 输出仍可能偶尔偏离指定格式，朗读过滤用于避免读出括号内翻译。
- 当前没有语音识别，用户输入仍以文字为主。
- 安装包尚未进行商业代码签名。
