# HiJapan 0.1.4 开发预览版

## 本次修复

- 修复部分 Windows 环境启动时短暂出现绿色矩形或残缺界面纹理的问题。
- Windows 启动时关闭 Electron 硬件加速，使用更稳定的软件渲染路径。
- HiJapan 启动画面改为固定全窗口最高层，避免主界面或中间绘制帧提前暴露。
- 启动画面最短显示时间从 1.6 秒延长至约 2.6 秒，并继续等待本地数据库快照准备完成。
- BrowserWindow 初始背景改为接近启动画面天空的蓝色，降低 HTML 首帧出现前的色彩跳变。

## 原因说明

绿色矩形不是应用设计的加载组件，也不是每个软件必然出现。截图特征符合 Chromium 合成器在特定显卡驱动、远程桌面或受限运行环境下短暂显示异常 GPU 纹理。DOM 层单纯提高 `z-index` 不能可靠修复合成器自身的问题，因此本版本同时关闭硬件加速并保留全屏启动遮罩。

## 影响

- 课程、AI 对话、系统朗读和本地数据结构没有变化。
- 软件渲染可能略微增加 CPU 使用，但当前界面以文字和静态卡片为主，影响预计很小。
- 教材包版本仍独立为 `0.1.0`，软件版本为 `0.1.4`。

教材仍处于 `draft_needs_native_review`，安装包尚未进行商业代码签名。
