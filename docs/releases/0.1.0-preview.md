# HiJapan 0.1.0 开发预览版

本版本用于验证 Windows 桌面端架构、旅行日语课程、学习记录、复习流程和用户自带 AI API 的对话闭环。

## 已包含

- 纯本地 Electron + React + SQLite 桌面应用，无自建服务器。
- 酒店住宿、餐厅点餐、购物付款、景点预约四个重点场景，共 20 课。
- 438 个词汇、231 条语句、30 个微语法、72 行固定对话。
- 今日计划、课程学习器、系统日语朗读、难度标记和间隔复习。
- OpenAI-compatible BYOK 配置、连接测试、文字角色对话和结构化复盘。
- API Key 由 Electron 主进程调用 Windows 系统加密能力保存，不进入 SQLite、日志或备份。
- 本地备份、恢复和全部数据删除。

## 预览版限制

- 教材仍标记为 `draft_needs_native_review`，尚未通过日语母语者终审，不可视为正式教学内容。
- JLPT 页面和数据结构已预留，但没有用 AI 临时生成题库；N5—N1 课程需在题库审校后逐步开放。
- 当前 AI 对话为文字版；语音识别和跨平台发布不在本版本范围内。
- Windows 安装包尚未进行商业代码签名，系统可能显示未知发布者提示。

正式发布前必须让 `npm run release:check` 通过。
