# HiJapan 0.1.5 开发预览版

发布日期：2026-10-29

## 新增内容

- 新增 5 节五十音基础课程，每节学习两行，从「あ行・か行」到「ら行・わ行」，共覆盖 46 个清音假名。
- 每个假名同时学习平假名、片假名和罗马音；课程词例显示日语写法、平假名注音和中文含义。
- 词例严格限制为只使用当前及此前课程已经学过的假名。
- 新增三列配对复习，可自主选择本节题库或累计已学假名题库。第一节没有此前内容，因此不显示累计复习。
- 每节进入时可自由选择完整学习、直接连线、直接翻牌或标记掌握；完整学习中也可分别跳过认识和词语环节。
- 新增可选翻牌游戏，随机使用平假名、片假名和罗马音组成配对；牌背升级为专门绘制的鸟居与樱花和纸插画。
- 五十音朗读按钮精简为圆形喇叭图标，连线页面的默认说明缩短为“请匹配”。
- 基础测试和游戏完成情况保存在本机 SQLite，并纳入学习备份和全部数据删除。

## 使用边界

- 五十音课程、判题、进度和系统朗读完全在本机运行，不使用 AI API。
- 连线和游戏都可以跳过；全部五节可自由进入，标记掌握只影响本地完成进度，不妨碍以后重新学习。
- 当前五十音词例仍标记为 `draft_needs_native_review`，不应视为已经完成日语母语者专业审校的正式教材。

## 版本说明

项目实际使用语义版本 `0.1.5`，这是从现有 `0.1.4` 升级的开发预览版。
