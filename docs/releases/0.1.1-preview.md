# HiJapan 0.1.1 开发预览版

本版本修复 Windows 图标交付与版本辨识问题，并保留 0.1.0 的全部学习功能。

## 变化

- 为应用可执行文件和 Squirrel 安装包嵌入“鸟居 + 日”Windows ICO。
- 设置稳定的 Windows AppUserModelID，供任务栏、快捷方式和通知正确识别应用。
- 使用新的 `0.1.1` 安装包与便携包文件名，避免覆盖同名 0.1.0 后继续显示旧图标缓存。
- 继续使用樱花、富士山、鸟居和海面组成的 HiJapan 启动画面。
- 保留 GitHub 项目首页、用户手册和开发者手册三份文档。

## 升级提示

如果曾解压 0.1.0 便携版，请把 0.1.1 解压到一个新文件夹，不要覆盖旧文件夹。安装版用户可运行 0.1.1 安装包升级。若资源管理器仍显示旧图标，关闭对应资源管理器窗口后重新打开即可；新的 EXE 已内嵌新图标。

## 预览版限制

- 教材仍标记为 `draft_needs_native_review`，不可视为正式审校教材。
- JLPT 正式题库、语音识别和代码签名仍不在本版本中。
