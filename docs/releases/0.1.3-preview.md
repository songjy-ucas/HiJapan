# HiJapan 0.1.3 开发预览版

## 本次修复

- 设置页不再硬编码显示 `v0.1.0`，改为从当前运行的 Electron 可执行程序读取真实版本。
- 首页原来的“内容版本 0.1.0”实际指教材包版本，但容易被误认为软件版本；现改为显示“软件版本 0.1.3”。
- 设置页中的内容数据版本明确改称“教材包版本”，继续独立显示当前教材包的 `0.1.0`。
- 增加自动测试，确保界面所用版本号来自应用包版本。
- 用户说明补充安装版、便携版和不同版本默认共用本地应用数据的行为。

## 数据兼容性

- 从 0.1.0、0.1.1 或 0.1.2 升级时继续使用同一份本地 SQLite、课程进度和加密 AI 配置，不会再次进入首次配置。
- 默认应用数据目录由 Electron 根据应用名称和当前 Windows 账户确定；升级不会删除它。
- 需要重新配置时，可在“设置 → 删除全部本地数据”中清空业务数据和加密密钥。操作前建议先导出备份。

## 继承自 0.1.2

- 近 7 天 AI 对话历史、继续未结束对话和历史删除。
- AI 双语回复格式以及仅朗读日语正文的系统 TTS 处理。

教材仍处于 `draft_needs_native_review`，安装包尚未进行商业代码签名。

本次界面文字修复继续使用 `0.1.3` 版本号，没有提升为新版本。当前交付的是修正版便携 ZIP，请完整解压到新目录运行。旧的 0.1.3 Setup 没有包含本次修复，已从主要交付目录移开；当前受限构建环境无法执行 Squirrel 所需的 7-Zip 工具，因此没有生成新 Setup。用户数据目录不会因切换到便携包而改变。
